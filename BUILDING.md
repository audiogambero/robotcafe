# How to build:

First, make sure you have downloaded the latest GBDK-2020 for your platform, and place it at the same level as this project repo
To build: run 'make'. It will create a directory called 'obj', containing intermediate files along with the actual ROM you want to test.
Simply run the ROM (robotcafe.gb) in your preferred emulator, or use the Emulicious Debugger extension within VS Code.

### Graphics workflow
Modify graphics, save file, export .c and .h files, rebuild, run in emulator
